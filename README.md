# SauceDemo – Manual Testing Project

## Project Overview
This project focuses on manual testing of the SauceDemo e-commerce web application.

The objective is to verify application functionality, identify defects, and document testing activities using industry-standard QA practices.

## Application Under Test
- Application: https://www.saucedemo.com/
- Testing Type: Manual Testing
- Domain: E-commerce

## Testing Scope
- Login and Authentication
- Product Inventory
- Product Sorting
- Shopping Cart
- Checkout
- Logout

## Testing Tools
- Microsoft Excel – Test Documentation
- Jira – Defect Tracking
- Chrome – Manual Testing
- GitHub – Project Documentation

## Project Deliverables
- Requirement Specification
- Test Scenarios
- Test Cases
- Requirement Traceability Matrix (RTM)
- Test Execution Report
- Bug Reports
